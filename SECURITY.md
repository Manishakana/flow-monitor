# Security policy

## Scope

Flow Monitor is a local network-visibility prototype. It collects connection metadata and local-network discovery observations; packet payload collection is intentionally not implemented.

## Reporting a vulnerability

Do not open a public issue for a suspected security vulnerability. Contact the repository owner privately with a description, affected version, reproduction steps, and impact.

## Data handling

The local SQLite database may contain IP addresses, MAC addresses, hostnames, connection metadata, and timestamps. It is excluded from version control and must not be published.
